SIMULADOR DE SOLITONS DE FALACO - COMO USAR
============================================

ARQUIVOS
  falaco_sim.py          programa em Python (simulador com gráficos)
  requirements.txt       bibliotecas necessárias (numpy e matplotlib)
  falaco_solitons.tex    documento com todas as fórmulas (abrir no TeXstudio)
  falaco_solitons_previa.pdf   prévia do documento já compilada

1) INSTALAR O PYTHON (uma vez só)
  - Baixe o Python 3.9 ou mais novo em https://www.python.org/downloads/
  - No instalador do Windows, MARQUE a caixa "Add python.exe to PATH".

2) INSTALAR AS BIBLIOTECAS (uma vez só)
  Abra o "Prompt de Comando" (Windows) na pasta dos arquivos e digite:
      python -m pip install -r requirements.txt
  (No Linux/Mac use python3 e pip3. No Linux, se a janela não abrir, instale também: sudo apt install python3-tk)
